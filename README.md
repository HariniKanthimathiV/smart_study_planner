# Study Planner

A responsive study planner built with HTML, CSS, and JavaScript. It starts empty so each user can enter their own tasks, subjects, and study sessions.

## Features
- Responsive layout for desktop, tablet, and mobile
- Add personal study tasks and optional subjects
- Mark tasks complete or incomplete and clear completed tasks
- Task counts and progress update automatically
- Add study sessions with your own times
- No prefilled or sample tasks, subjects, or schedule entries

## Run locally
Open `index.html` in any modern web browser. No installation or build tools are required.

Note: Entries are kept in the current page session and reset when the page is reloaded.
